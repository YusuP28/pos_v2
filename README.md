# POS v2 — Offline Point of Sale

Aplikasi Point of Sale (POS) **offline-first** untuk Android, dibangun dengan Flutter.

## Fitur

- Login multi-user + session persistence
- PIN Login (4 digit) + PIN Admin (6 digit)
- Produk & Kategori CRUD
- Retail POS + Checkout Tunai/QRIS/Kartu
- Shift Kas + Riwayat + Rekap
- Pengeluaran Kas
- Stock In + Laporan Stok
- Barcode Scanner + Cetak Label
- Printer Thermal Bluetooth + Logo
- QRIS Statis
- Laporan Penjualan + Export CSV
- Backup & Restore Database
- Manajemen User + Role Restriction

## Cara Install

1. Buka halaman Releases: https://github.com/YusuP28/pos_v2/releases
2. Download pos_v2_v1.0.0-beta.apk
3. Install di HP Android

Default login: admin / admin

## Teknologi

- Flutter 3.47.x + Dart
- Provider (state management)
- SQLite (sqflite)
- mobile_scanner (barcode)
- blue_thermal_printer (printer)
- GitHub Actions (CI/CD)
